# JOJO Director Brand Assets

**Positioning:** Scientific Scene Production Engine  
**Brand line:** A system that directs, produces and verifies scientific scenes.

This folder stores the current approved visual direction as editable SVG source files.

## Assets
- `jojo-director-mark.svg` — standalone symbol for app icon, favicon and compact UI use.
- `jojo-director-lockup.svg` — horizontal primary lockup with descriptor.
- `jojo-director-readme-hero.svg` — README hero artwork with calibration ticks; documentation display only, not a replacement for the app mark.
- `JOJO-DIRECTOR-BRAND-IDENTITY.md` — construction logic, palette, usage rules and release checklist.

## Functional palette
| Token | HEX | Meaning |
|---|---|---|
| Scene | `#00B3A6` | Scene structure, evidence and data |
| Produce | `#E6007E` | Creative and production actions |
| Verify | `#FF8A00` | Verification and feedback |
| Core | `#1A1A1A` | Core structure and typography |
| Paper | `#FAF8F2` | Warm neutral background |

## Design lineage
Original JOJO orbital mark → scientific-scene poster exploration → A/B/C concept comparison → A+C selection with Minimal style → remove play-triangle cue → functional brand system.

The current repository assets are SVG and remain editable. Raster exports and the 16:9 brand-evolution film are included in the downloadable desktop archive prepared separately. This repository folder does not claim that the brand is trademark-cleared or production-frozen.
