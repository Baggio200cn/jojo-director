## 1. 合作双方分别负责什么

### 学科合作者

1. 确定一个边界清楚的小课题；
2. 提供教材、标准、指南、论文、设备手册或真实实验素材；
3. 写明科学规则、适用条件、常见错误和禁止表达；
4. 在 JOJO 审核证据卡、场景规则和候选成果；
5. 对专业问题作出“通过、退回补证、退回修改”的结论。

### JOJO 项目组

1. 建目录、候选卡和审核任务；
2. 检查文件完整性、版本、权利和隐私；
3. 将规则转化为可执行的场景参数与验收断言；
4. 保留候选、审核、修订和版本记录；
5. 未经合作者确认，不将候选标记为批准投产。

### 合作者不承担的事项

- 不需要编写代码或训练模型；
- 不需要付费调用模型；
- 不需要接受“AI 已经生成，所以应该正确”的预设；
- 不应为了赶进度批准缺少依据的卡片。

## 2. 开始前：先确认一个课题

不要从“基础医学”或“生理学”整章开始。首题应能用一段短视频讲清一个明确机制。

基础医学可从以下方向选择：

- 心脏泵血过程与心输出量；
- 静息电位、动作电位与离子流；
- 细胞膜扩散、渗透与主动运输；
- 红细胞生成、血红蛋白、血型与输血原则。

也可以另选课题，但必须先明确学生对象、教学目标和验收人。

### 课题确认单

请合作者复制并填写：

```text
学科：
课题名称：
授课对象：
学生学完后应能解释或观察什么：
计划讲解时长：
专业审核人及单位：
主要参考资料：
不适合呈现的内容：
是否存在伦理、隐私或安全限制：
```

在课题组、真值来源和验收人没有确认前，JOJO 只建立待讨论目录，不创建正式医学证据卡。

## 3. 需要准备哪些素材

按“必需”和“可选”整理，不要求一次上传整门课程。

| 素材 | 必需程度 | 需要说明的内容 |
|---|---|---|
| 教材、指南、标准或论文 | 必需 | 标题、作者/机构、版本、年份、章节、页码、图表或原文位置 |
| 教学目标和学生观察点 | 必需 | 学生需要解释、辨别或操作什么 |
| 科学规则与限制条件 | 必需 | 正常顺序、方向、参数、单位、前提和例外 |
| 真实实验或操作素材 | 视课题而定 | 来源、拍摄时间、授权、可公开范围及对应步骤 |
| 教师口播或讲稿 | 可选 | 对应段落及版本；不能只凭讲稿替代科学真值 |
| PPT、图片和图表 | 可选 | 页码、出处、授权及需要保留的标注 |
| 错误示例或常见误解 | 建议提供 | 错在哪里、为什么错、学生如何判断 |
| 外部视频链接 | 可选 | 仅作发现与参考，不等于已授权生产素材 |

### 医学素材的特别限制

- 不上传患者姓名、身份证号、住院号、联系方式等身份信息；
- 不上传未经批准的人脸、病历、检验单、影像原始文件或可识别病例；
- 不用真实病例资料训练或测试公开演示；
- 涉及人体操作、用药、输血、急救或侵入性操作时，必须写明适用边界和禁止动作；
- AI 生成画面不得冒充真实手术、真实实验或真实患者。

## 4. 文件如何命名和整理

建议每个课题单独建立一个文件夹：

```text
课题名称/
  01-课题确认单.txt
  02-参考资料/
  03-真实实验素材/
  04-课件与讲稿/
  05-规则与错误示例/
```

文件名建议包含主题和版本，例如：

```text
细胞膜运输-教材摘录-v1.pdf
动作电位-离子流演示-v1.mp4
心脏泵血-常见错误-v1.txt
```

不要覆盖旧文件。修改后使用 `v2`，并在审核意见中说明修改内容。

## 5. 在网页版怎样上传素材

当前上传入口支持：MP4、MOV、WebM 视频，PNG、JPG、JPEG、WebP 图片，PDF 资料；文件夹上传还支持 UTF-8 编码的 TXT、Markdown 和 CSV 规则/清单文件。当前表单不接收 DOCX、PPTX 或 ZIP；这些文件请先联系管理员安排导入，不要通过修改扩展名绕过。

### 操作步骤

1. 打开管理员提供的 JOJO 候选环境地址并登录；
2. 返回首页，找到“教师投稿”；
3. 点击“选择文件”，选择对应素材；
4. 选择学科目录；没有合适目录时选择“新学科”，填写建议名称；
5. 填写课题名称，例如“静息电位与离子流”；
6. 选择权利声明：
   - **本人自制**：素材由您本人制作且有权提供；
   - **已获授权**：已经取得授权，需在简述中说明授权范围；
   - **仅参考不进片**：只用于研究和参考，不允许进入成片；
7. 在“简述”中写明版本、出处定位、授权限制和素材对应的教学过程；
8. 可点击“智能建议目录”查看系统建议，确认后再采用；
9. 点击“提交入库”；
10. 将提交结果、文件名和课题名称告知管理员，由双方核对是否收到。

### 文件夹上传与自动归类

1. 将同一课题的资料按子文件夹整理，删除无关文件、缓存、账号配置和隐私资料；
2. 在“教师投稿”中点击“选择文件夹”，选中课题文件夹；
3. 确认文件数量和权利声明，填写课题说明；
4. 可指定学科/课题目录，也可选择“自动归类（待审核）”；
5. 点击“上传并分析文件夹”；
6. 查看后台返回的接收、拒绝和重复文件清单，逐项核对目录与分析结果。

后台会保留相对路径，检查格式签名，计算内容哈希并去重。归类使用本地规则，分析文件名、目录、备注及可读取的 UTF-8 文本；不会自动调用付费模型。PDF、图片和视频不能仅凭文件名视为已完成专业内容理解，所有归类结果都需要人工审核。

不支持的格式、损坏文件、重复内容和无效路径会在回执中说明，不要为了得到“全部通过”而重复上传或修改扩展名。

### 上传后需要确认

- 文件能否打开，是否传错版本；
- 课题和目录是否正确；
- 权利声明是否准确；
- 素材是否含隐私或禁止外发内容；
- 哪些片段可用于生产，哪些只能参考。

**上传成功不等于科学审核通过，也不等于允许投产。**

### 数据保存与后续对齐

当前候选环境中，通过校验的文件实际保存在服务器 `/srv/jojo-storage/candidate-moma/backend/assets/`，使用随机素材 ID 命名；原始相对路径、内容哈希、权利和分析信息保存在 `/srv/jojo-storage/candidate-moma/backend/jojo.db` 的素材记录中。未通过、损坏或路径无效的文件不会写入素材目录。

文件夹批次按以下状态流转：

1. **分析完成，待教师审核**：教师查看逐项归类和分析结果；
2. **教师提出修改意见**：记录具体问题，不删除原批次；
3. **教师确认并暂时归档**：表示本批次已完成教师侧核对，不代表批准投产；
4. **管理员与技术团队对齐**：确认目录、证据、权利、后续制作边界和版本。

每一步都保存审核意见、操作角色和时间。归档只表示暂存，不得据此自动生成或发布课程视频。

## 6. 规则审核怎样操作

进入“科学素材训练库”，选择学科、候选类型和待审核对象。点击候选卡片后，右侧显示详情和审核表单。

### 逐项检查

1. **用途与边界**：是否讲清教学目标，适用学生是否正确；
2. **来源**：能否定位到教材页码、指南条目、论文图表、设备手册章节或真实素材时间码；
3. **权利**：是否允许当前用途，能否外发，是否只能参考；
4. **输入与参数**：名称、单位、默认值和必需项是否正确；
5. **结构**：器官、设备、分子、代码对象或部件关系是否正确；
6. **动作与时序**：方向、顺序、持续时间、因果和反馈是否正确；
7. **禁止路线**：是否明确禁止用生成式画面冒充真实实验；
8. **验收断言**：能否根据规则判断“合格/不合格”，而不是只写“画面自然”；
9. **缺项**：证据卡、样本、断言或运行环境是否仍需补齐。

### 填写审核记录

1. 在“审核人”中填写姓名和单位；
2. 选择抽检结论；
3. 勾选实际完成的检查项，不要勾选未执行的项目；
4. 在审核意见中写明依据、问题位置和修改要求；
5. 点击“保存审核记录”；
6. 刷新页面，在“审核历史”中确认记录存在。

### 三种结论怎样选择

- **抽检通过**：本次抽检范围内未发现阻断问题，但仍不代表批准投产。提交前必须实际核对来源、权利范围和适用范围；
- **退回补证**：内容可能正确，但缺教材、标准、原始论文、实测记录或授权证明。必须写清缺什么；
- **退回修改**：发现明确错误或不合理表达。必须写清改哪里、依据是什么。

审核记录绑定当时的内容哈希。候选内容变化后，需要重新审核；历史记录不会被覆盖。

## 7. 怎样写一条可执行的审核意见

不要只写“不科学”“不好看”“再准确一点”。

推荐格式：

```text
问题场景：
对应素材及版本：
问题描述：
正确规则或依据：
需要怎样修改：
复核时需要观察什么：
```

基础医学示例（仅示范写法，不作为医学内容依据）：

```text
问题场景：动作电位-离子流
对应素材及版本：教材摘录-v1，第 X 章第 X 页
问题描述：图中离子方向与当前膜电位阶段的关系没有标清
正确规则或依据：请按所采用教材的分期与离子流说明逐项核对
需要怎样修改：补充分期、方向、时间和图例，不用无依据动画补空白
复核时需要观察什么：阶段名称、离子方向、膜电位曲线及口播是否一致
```

## 8. 候选视频怎样验收

- 先核对采用的任务包、场景和候选版本；
- 对照来源逐项检查结构、参数、动作、时序、口播和字幕；
- 真实素材必须能回查，合成或生成内容必须明确标识；
- 缺少真实素材时应显示待补，不得用 AI 画面补齐真实现场；
- 只需修改一个场景时，使用“退回此场景”，不要整段重制；
- 新候选生成后，复核修改场景，同时确认其他场景未被意外改变；
- 科学审核与教学可用性审核分别记录，不能用“画面精美”代替科学正确。

## 9. 首轮合作完成标准

一个课题的首轮合作，至少应具备：

- 一份填写完整的课题确认单；
- 一组可定位、版本明确的真值来源；
- 一套科学规则、适用范围和禁止表达；
- 至少一个可审核的候选场景；
- 合作者提交的审核记录；
- 必要的退回补证或修订记录；
- 明确的专业验收人。

“已上传素材”“已生成视频”“抽检通过”都不能单独代表课题完成。
