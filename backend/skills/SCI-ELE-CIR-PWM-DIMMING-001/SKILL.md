# 使用边界

本 Skill 只用于验证确定性 2D 与真实素材的组合。占空比必须按高电平持续时间 ÷ 周期计算，三组比较必须保持周期一致。生成式图片不能替代波形。

# 输入

- 周期及单位；
- 占空比序列；
- 口播与字幕来源；
- 真实调光素材及权利信息。

缺少任一关键输入时保留缺项，不生成确定教学结论。

# 验收

逐项执行 `qc/rules.yaml`，核对周期、占空比顺序、口播和字幕一致性，以及真实素材出处。所有修正必须创建新场景版本并保留旧版。
