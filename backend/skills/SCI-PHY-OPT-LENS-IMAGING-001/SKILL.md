# 使用边界

本 Skill 用程序绘制透镜和光线，不根据图片自由猜测光路。焦距、物距、光线方向和焦点必须来自明确参数与来源。真实实验画面只通过授权素材使用。

# 输入

- 焦距与物距及单位；
- 光具座、透镜、物体和光屏的场景要求；
- 教学目标和学生需要观察的关系；
- 可选真实实验素材。

# 验收

逐项检查 `qc/rules.yaml`，确认光线方向、焦点位置、虚实像表述和画面一致。缺少结构或参数依据时只输出缺口，不进入生产。
